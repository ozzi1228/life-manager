## 6. 대안과 판단 근거 (주요 결정)

### 6.1 고정 지출 해지: 목록에서 빼기 vs 상태 표시 (사용자 질문)
- 선택: **상태 3단계(이용 중 / 해지 예정 / 해지됨) + 해지됨은 맨 아래 접힘.**
- 기각한 대안: (a) 목록에서 삭제 — 이력·메모 손실, 실수 삭제와 구분 불가. (b) 해지 표시만 하고 같은 목록에 — 이용 중 항목을 훑기 어려움.

### 6.2 연간 목표: 별도 저장 vs 모아보기
- 선택: **연도 지정 목표 모아보기**(대화 합의). 기각: 별도 "새해 목표" 테이블 — 장기 목표와 중복 등록.

### 6.3 API 로그: DB vs 날짜별 파일
- 선택: **최근 30일 DB + 날짜별 압축 JSON Lines 1년.** 사용자 아이디어(날짜별 텍스트 파일)를 채택하면서 최근 로그 검색성을 확보.

### 6.4 AI 기본 연결: 구독 vs API 키
- 선택: **API 키 기본.** 근거: 3사 모두 웹 구독에 API 사용권 없음, Anthropic·Google은 구독 자격증명의 제3자 앱 사용 금지, OpenAI 플랜 사용은 로컬·파트너 한정.

### 6.5 펫 렌더링: 형식별 렌더러 vs 단일 스프라이트 렌더러
- 선택: **단일 스프라이트 렌더러 + 업로드 시 변환.** 근거: 외형·행동 분리 원칙, 사용자가 형식 무관하다고 함, 렌더러 하나가 성능·테스트에 유리.

### 6.6 카드 추천: AI 계산 vs 서버 계산 엔진
- 선택: **서버 계산 엔진 + AI는 질문·설명.** 근거: 숫자 정확성, AI 없이도 동작, 같은 결과 보장.

### 6.7 운영 방식: 클라우드 vs 본인 PC (D-034)
- 선택: **본인 PC 자가 운영**(사용자 결정). 문서 추천은 클라우드였다.
- 선택으로 얻는 것: 운영비 거의 없음, 데이터가 내 PC에, ChatGPT 계정 플랜 사용 경로의 로컬 호스팅 조건 충족.
- 보완 설계: Tailscale 사설망으로 포트 없이 외부 접속(D-043), 부팅 시 자동 시작(Q-161), PC가 꺼졌던 동안의 작업 따라잡기·놓친 알림 모음(16 §5.5), 하트비트 끊김 알림, PC 밖 두 곳 백업(D-049), 클라우드 이전 경로 유지(16 §5.8).

### 6.9 외부 접속: Cloudflare Tunnel vs Tailscale (D-043)
- 선택: **Tailscale 사설망**(사용자 결정). 문서 추천은 Cloudflare Tunnel이었다.
- 얻는 것: 앱이 인터넷에 전혀 공개되지 않음, 도메인 비용 없음, ChatGPT 계정 플랜 사용의 "로컬 호스팅" 조건에 더 잘 맞음.
- 잃는 것과 대체: 카카오·네이버 연결 끊기 웹훅 → 다음 로그인 때 감지. 구글 캘린더 실시간 푸시 → 15분 주기 동기화. 외부 가동 확인 → 하트비트 방식. 모든 기기에 Tailscale 설치·상시 연결 필요.

### 6.8 참은 소비 채우기: 자동 vs 사용자 확인 (D-036)
- 선택: **월 정산 때 조건에 맞는 위시를 자동으로 넣고, 정산 화면에서 뺄 수 있게.** 사용자가 "넣어야 해"라고 했으므로 기본은 자동이다.
- 위시 자동 포함은 월말(다음 달 1일)에만 한다. "한 달 내내 안 샀다"는 조건은 달이 끝나야 판정되기 때문이다. 대신 이번 달에는 후보와 합계를 미리 보여 준다.
- 사치 분류 자체의 예산 초과액은 더하지 않는다(사치 지출 전액이 이미 들어가므로 이중 계산).
