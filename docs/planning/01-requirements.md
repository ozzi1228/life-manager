# 01. 요구사항 명세

> 문서 상태: 초안 v0.1 · 작성일 2026-11-01
> 표식 규칙은 [00 개요 §0](00-overview.md#0-이-문서-묶음을-읽는-법)을 따른다.

## 1. 우선순위 정의 [제안]

| 등급 | 의미 | 포함 시점 |
|---|---|---|
| **P0** | 없으면 앱을 쓸 이유가 없는 핵심 | MVP (1차 출시) |
| **P1** | 핵심 경험을 완성하는 기능 | 2차 |
| **P2** | 있으면 좋은 확장 | 3차 이후 |
| **V** | 검증 후 우선순위 결정 | 검증 결과에 따라 |

요구사항 번호 규칙: `FR-<영역>-<번호>` (기능), `NFR-<분류>-<번호>` (비기능). 영역 코드: COM 공통, AUTH 계정, HOME 홈, GOAL 목표, TRK 트래커, FIN 돈, CAL 일정, JRN 일기, MED 작품 기록, WISH 위시, HLT 건강, PET 펫, AI 비서, DATA 데이터 관리, SET 설정.
