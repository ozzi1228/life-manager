# 05. 목표와 월간 트래커

> 문서 상태: 초안 v0.1 · 작성일 2026-11-01
> 화면: [04 §5](04-screen-specifications.md#5-목표) · 데이터: [14 §4.3](14-data-model.md) · API: [15 §5](15-api-specifications.md)

## 1. 사용자 요구 원문 정리 [확정]

- 단기·중기·장기 목표를 설정한다.
- 목표를 달성하면 체크한다. 기간도 설정한다. 기간은 "그냥 연도 정도로만".
- 각 목표를 카테고리로 나눈다. 예: 커리어, 자산, 다이어트, 독서.
- 연도별로 새해 목표를 쓰고 달성 여부를 체크한다.
- 월별 목표를 날짜별로 체크하는 목표 트래킹이 있어야 한다.
  - 목표가 한 축, 그 달의 날짜가 다른 축.
  - 관련 메모를 간단히 넣는다.
  - 체크박스가 아니라, 체크하면 칸 배경색이 바뀌고 메모는 그 칸 안에 텍스트로 들어간다.
  - 목표별 배경색을 다르게 설정할 수 있다. 색상 팔레트 제공 필수.

## 2. 핵심 개념 분리 [제안: ChatGPT 대화에서 제시]

| 개념 | 화면 이름 | 무엇 | 예 | 체크 단위 |
|---|---|---|---|---|
| 목표 | 전체 목표 / 연도별 | 이루고 싶은 결과 | "2027년 자산 1억", "연간 독서 24권" | 목표 전체를 한 번 달성 체크 |
| 트래커 항목 | 월간 | 매일 반복하는 실천 | "독서 30분", "운동", "영어 공부" | 날짜별 칸 |

둘을 섞으면 "자산 1억" 같은 결과 목표를 날짜별 칸으로 관리하게 되는 문제가 생긴다. 대신 트래커 항목을 목표에 **연결**할 수 있다(선택).

> 용어: 사용자는 트래커 행도 "월별 목표"라고 불렀다. 결과 목표와 헷갈리지 않도록 화면에서는 트래커 탭 이름을 `월간`, 각 줄을 `항목`이라 부른다. [확정 D-047]

## 3. 목표

### 3.1 필드

| 필드 | 화면 라벨 | 필수 | 값 | 근거 |
|---|---|---|---|---|
| 제목 | 목표 | 필수 | 1~60자 | [확정] |
| 기간 구분 | 기간 구분 | 필수 | 단기 / 중기 / 장기 (기본 단기) | [확정: 3구분] |
| 기간 | 기간 | 선택 | 한 해(YYYY) / 여러 해(YYYY~YYYY) / 정하지 않음 | [확정: 연도 정도] [제안: 형태] |
| 카테고리 | 카테고리 | 선택 | 사용자 카테고리 1개 | [확정] |
| 상태 | (배지) | 자동 | 진행 중 / 달성 / 보류 / 포기 | [확정: 달성 체크] [제안: 보류·포기] |
| 달성일 | 달성한 날 | 자동 | 달성 체크한 날(수정 가능) | [제안] |
| 수치 목표 | 숫자로 진행률 보기 | 선택 | 목표 값, 현재 값, 단위 | [제안] |
| 자동 연결 | (수치 목표 하위) | 선택 | 없음 / 완독한 책 / 본 영화 / 본 드라마 | [제안] |
| 메모 | 메모 | 선택 | 텍스트 | [제안] |

### 3.2 규칙 [제안]

1. **단기·중기·장기는 자동 판정하지 않는다.** 사용자마다 기준이 다르다. ⓘ에 예시 기준만 보여 준다.
2. **연간(새해) 목표는 별도 데이터가 아니다.** 기간에 그 연도가 포함된 목표를 모아 보는 화면이다. 같은 목표가 장기 목표와 새해 목표에 중복 등록되지 않는다.
3. 기간이 "정하지 않음"인 목표는 연도별 화면에 나타나지 않는다.
4. 여러 해 목표는 포함된 모든 연도 화면에 보인다. 연도별로 따로 달성 체크하지 않는다. [18 Q-021]
5. 달성 체크는 되돌릴 수 있다(토스트 `되돌리기`, 상세에서 `진행 중으로 되돌리기`).
6. 수치 목표의 현재 값이 목표 값에 도달해도 **자동으로 달성 처리하지 않는다.** "목표 값에 도달했어요! 달성으로 표시할까요?" 토스트 + `[달성]`. (예: 24권 목표를 넘겨 더 읽을 수도 있음)
7. 기간이 지난 진행 중 목표: 연도가 끝나면 다음 해 1월 첫 진입 시 "작년 목표 정리" 안내(InlineNotice) → 각 목표 `달성` / `올해로 옮기기`(기간을 새 연도로) / `포기` / `그대로 두기`. [제안]

### 3.3 카테고리

- 기본: 커리어, 자산, 다이어트, 건강, 독서, 학습, 생활, 관계. [확정: 커리어·자산·다이어트·독서는 사용자 예시] [제안: 나머지]
- 사용자 추가·이름 변경·순서·삭제. 최대 30개.
- 카테고리마다 아이콘(선택, lucide 목록에서). 색은 쓰지 않는다(트래커 색과 혼동 방지). [제안]
- 삭제 시 목표는 `분류 없음`이 된다(목표는 지워지지 않음).

### 3.4 수치 목표 자동 연결 [제안]

| 연결 | 더해지는 조건 | 빠지는 조건 |
|---|---|---|
| 완독한 책 | 작품 기록(책) 상태가 `완독`이 되고, 종료일이 목표 기간 안 | 상태를 완독에서 바꾸거나 기록 삭제 |
| 본 영화 | 영화 기록의 본 날이 목표 기간 안 | 기록 삭제·날짜 변경 |
| 본 드라마 | 드라마 상태 `다 봄` + 종료일이 기간 안 | 동일 |

- 현재 값 = 자동 집계 + 수동 조정(± 버튼). 수동 조정은 별도로 저장해 자동 집계가 다시 계산돼도 사라지지 않는다.
- 기간이 정하지 않음이면 전체 기간 집계.

## 4. 월간 트래커

### 4.1 구조

```
트래커 항목(행)  ── 월별 사용 여부(어느 달에 보일지)
     │
     └── 칸 기록(항목 × 날짜): 완료 여부, 메모
```

- 항목은 여러 달에 걸쳐 같은 것을 쓴다(지난달 항목 이어 쓰기). 색·이름을 바꾸면 모든 달에 반영된다. 특정 달만 다른 색을 쓰고 싶다는 요구가 생기면 재검토. [제안]
- 항목이 어느 달에 보이는지는 "월별 사용 목록"으로 관리한다(한 달에서 빼도 다른 달 기록은 그대로).

### 4.2 칸 규칙

| 규칙 | 내용 | 근거 |
|---|---|---|
| 상태 | 완료 / 미완료(기록 없음) 두 가지 | [확정: 색 칸] |
| 메모 | 0~40자. 완료 여부와 독립(메모만 있는 미완료 칸 가능) | [확정: 칸 안 메모] [제안: 길이·독립] |
| 미래 날짜 | 편집 불가 | [제안] |
| 과거 날짜 | 편집 가능, 기한 없음 | [제안] |
| 날짜 기준 | 사용자 시간대(기본 Asia/Seoul)의 자정 기준 | [제안] |
| 새벽 기록 | "하루 시작 시각" 설정(기본 0시, 예: 새벽 4시로 바꾸면 3시에 체크해도 전날 칸) | [제안] P2 |
| 표시 | 완료: 항목 색 배경 + (메모 없으면) 작은 체크 / 미완료: muted 배경 | [확정+제안] |
| 메모 표시 | 칸 크기에 맞춰 1~2줄, 넘치면 말줄임(…), 너무 좁으면 점(•) | [제안] |

- "부분 완료"(반만 함) 같은 3단계 상태는 두지 않는다. 필요하면 메모로 남긴다. 요구가 생기면 [18 Q-023]에서 재검토.

### 4.3 색상

- 팔레트와 글자색 자동 결정: [03 §3.1.4](03-design-system.md).
- 새 항목의 기본 색: 그 달에 아직 쓰지 않은 팔레트 색을 팔레트 순서대로. 12개를 다 쓰면 처음부터 반복. [제안]
- 색은 HEX로 저장한다. 팔레트가 바뀌어도 사용자가 고른 색은 그대로다.

### 4.4 통계 [제안] P1

| 통계 | 계산 | 표시 위치 |
|---|---|---|
| 항목별 월 완료 | 완료 칸 수 / 그 달 지난 날 수(오늘 포함) | 행 끝 `12/30` (PC), 모바일 하단 요약 |
| 월 전체 달성률 | 전체 완료 칸 / (항목 수 × 지난 날 수) | 트래커 머리 |
| 연속 기록 | 오늘(또는 어제)까지 이어진 완료 일수 | 항목 상세 "7일 연속" |
| 목표 연결 | 연결된 항목들의 이번 달 완료 | 목표 상세 |

- 분모는 "그 달의 전체 일수"가 아니라 "지난 날 수"를 쓴다. 월초에 달성률이 낮게 보이는 문제를 피한다. 지난 달은 전체 일수.

### 4.5 알림 [제안] P1

| 알림 | 기본 | 내용 |
|---|---|---|
| 체크 누락 | 끔 | 설정 시각(기본 오후 9시)에 오늘 미완료 항목이 있으면 "오늘 운동, 영어를 아직 체크하지 않았어요" |
| 어제 놓침 | 끔 | 아침 첫 실행 시 펫 말풍선 "어제 독서 체크를 안 했어요" (알림 센터에도) |

### 4.6 예외 상황

| 상황 | 처리 |
|---|---|
| 한 달에 항목이 20개 이상 | PC는 세로 스크롤(머리 고정). 모바일 항목 열 이름 말줄임 + 길게 눌러 전체 이름 |
| 항목 이름이 매우 김 | 60자 제한, 행 머리는 말줄임 + Tooltip |
| 같은 칸을 두 기기에서 동시에 바꿈 | 마지막 저장이 이김(칸 단위라 충돌 영향 작음). 변경 이력에 둘 다 남음 [제안] |
| 오프라인에서 여러 칸 변경 | 기기 대기열 → 재연결 시 순서대로 전송, 멱등 키로 중복 방지 |
| 시간대 변경(해외 여행) | 칸 날짜는 기기 시간대 기준이 아니라 사용자 설정 시간대 기준. 설정에서 바꿀 수 있음 |
| 항목 삭제 후 복구 | 모든 칸 기록이 함께 복구 |
| 이번 달에서만 빼기 | 그 달 칸 기록은 보존(다시 넣으면 보임) |

## 5. 데이터 연결

| 연결 | 방향 | 규칙 |
|---|---|---|
| 트래커 항목 → 목표 | 선택, 다대일 | 목표 상세에 실천 통계 표시. 목표 삭제 시 연결만 끊김 |
| 작품 기록 → 수치 목표 | 자동 집계 | §3.4 |
| 홈 "오늘의 목표" | 같은 칸 데이터 | 이번 달 사용 중인 항목만 |
| 빠른 추가 "목표 체크" | 같은 칸 데이터 | |
| 펫 | 이벤트 | 하루 모든 항목 완료 → 축하 동작, 목표 달성 → 축하 동작 |
| AI | 조회 | "이번 주에 운동 몇 번 했지?" → 트래커 칸 조회 도구 |
