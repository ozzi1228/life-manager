# 08. 일기와 작품 기록 (독서·영화·드라마)

> 문서 상태: 초안 v0.1 · 작성일 2026-11-01
> 화면: [04 §7.1~7.5](04-screen-specifications.md#7-기록) · 데이터: [14 §4.6](14-data-model.md) · API: [15 §8](15-api-specifications.md) · 조사: [19 §6](19-integration-research.md#6-작품-정보표지포스터)

## 1. 사용자 요구 [확정]

**일기**
- 일기나 다이어리처럼 쓸 수 있되, 한 날짜에도 여러 주제로 쓸 수 있다.
- 사진을 포함한 일기.

**작품 기록**
- 월간 트래커 방식을 독서 기록에 응용할 수 있을 것 같다 — 독서 캘린더, 영화·드라마 캘린더 같은 것.
- 어떤 책을 언제부터 언제까지 읽었는지, 완독인지 중도 포기인지 기록.
- 영화·드라마도 언제 봤는지 기록.
- 감상 기록.
- 책 표지, 영화·드라마 포스터를 넣어 캘린더에서 모아 본다.

## 2. 일기

### 2.1 구조 [제안]

```
날짜(하루) ─┬─ 글 1 (주제: 회고)  ─ 사진 n장
            ├─ 글 2 (주제: 일상)
            └─ 글 3 (주제: 감사)
```

- 글 하나 = 날짜 1개 + 주제 1개 + 제목(선택) + 본문 + 사진(0~10장).
- 같은 날 같은 주제로 글 두 개도 허용(제한하지 않음).
- "하루"를 별도 데이터로 두지 않는다. 날짜별 모음은 같은 날짜의 글을 모아 보여 주는 화면이다.

### 2.2 주제

- 기본 [제안]: 일상, 회고, 감사, 여행, 생각, 업무. 사용자 추가·이름 변경·순서·숨기기.
- 주제마다 색 점(트래커 팔레트 재사용)과 아이콘(선택).
- 주제 삭제: 소속 글은 `주제 없음`.

### 2.3 본문 [제안]

- 서식: 굵게, 기울임, 제목 1단계, 목록, 체크 목록, 인용, 링크. 표·코드는 제외(일기에 불필요).
- 저장 형식: 마크다운 텍스트. 검색·내보내기가 쉽고 에디터 교체가 쉽다.
- 에디터 라이브러리는 [미결정 Q-070] (후보: Tiptap, Lexical, 단순 Textarea + 마크다운 미리보기).
- 길이 제한 50,000자.

### 2.4 사진

| 항목 | 규칙 [제안] |
|---|---|
| 개수 | 글당 10장 |
| 형식 | JPEG, PNG, WebP, HEIC(서버에서 변환) |
| 크기 | 원본 20MB 이하 |
| 처리 | 서버에서 EXIF 위치 정보 제거(개인정보), 회전 보정, 썸네일 320px·본문 1280px WebP 생성, 원본 보관 [미결정 Q-071: 원본 보관 여부·비용] |
| 접근 | 소유자만, 서명된 임시 주소(만료 1시간) |
| 업로드 | 앱 서버로 스트리밍 업로드 → 데이터 폴더 저장(본인 PC 운영, D-034). 진행률 표시 [제안] |

### 2.5 임시 저장·충돌

- 작성 중 5초마다 기기(IndexedDB)에 임시 저장. 서버 저장은 `저장` 시.
- 같은 글을 두 기기에서 수정: 저장 시 버전이 다르면 "다른 기기에서 먼저 수정했어요" Dialog → `내 내용으로 저장`(덮어쓰기, 이전 내용은 변경 이력에) / `최신 내용 보기`(내 작성분은 임시 저장에 남김).

### 2.6 추가 기능 [제안]

| 기능 | 우선 |
|---|---|
| 기분 기록(이모지 5단계) | P2 |
| "1년 전 오늘" 회상(홈 위젯) | P2 |
| 날짜별 모음에 그날의 다른 기록 요약(지출 합계, 트래커, 작품) | P1 |
| 일기 잠금(건강과 같은 잠금 방식) | P2 [미결정 Q-072] |

## 3. 작품 기록

### 3.1 종류와 상태 [확정: 책 완독/중도 포기, 영화·드라마 본 날짜] [제안: 상태 이름]

| 종류 | 상태 | 날짜 |
|---|---|---|
| 책 | 읽는 중 / 완독 / 중도 포기 | 시작일 ~ 종료일 (읽는 중이면 종료일 없음) |
| 영화 | 봤어요 (+ 다시 본 기록) | 본 날 (여러 번 본 경우 날짜 여러 개) |
| 드라마 | 보는 중 / 다 봄 / 중도 포기 | 시작일 ~ 종료일 |

- 다시 읽기·다시 보기: 같은 작품에 "기록"을 여러 번 둔다(작품 정보 1개 + 감상 기록 n개). 예: 2024년에 읽고 2026년에 다시 읽음. [제안]
- 드라마 시즌: 시즌을 별도 작품으로 기록(검색 결과에서 시즌 선택). [제안]

### 3.2 필드

| 필드 | 필수 | 비고 |
|---|---|---|
| 종류 | 필수 | |
| 제목 | 필수 | |
| 원제·저자·감독·출연·출판사·연도 | 선택 | 검색 시 자동 |
| 표지·포스터 | 선택 | 검색 이미지 또는 직접 업로드 [확정: 이미지 넣기] |
| 상태·날짜 | 필수 | §3.1 |
| 별점 | 선택 | 0.5~5 [제안] |
| 감상 | 선택 | 긴 글 가능 [확정] |
| 한 줄 평 | 선택 | 캘린더 Hover Card에 표시 [제안] |
| 어디서 | 선택 | 넷플릭스, 영화관, 전자책 등 칩 |
| 쪽수·진행률 | 선택 | 책 읽는 중 진행 표시 P2 |
| 위시 출처 | 자동 | 위시에서 시작한 경우 |

### 3.3 포스터 캘린더 규칙 [확정: 캘린더에서 모아보기] [제안: 배치 규칙]

| 종류 | 캘린더에 놓이는 날 | 기간 표시 |
|---|---|---|
| 책 완독·중도 포기 | 종료일 | 선택: 시작~종료를 얇은 띠로 표시(설정) |
| 책 읽는 중 | 표시 안 함(상단 "읽는 중" 띠) | |
| 영화 | 본 날 | |
| 드라마 다 봄 | 종료일 | |
| 드라마 보는 중 | 시작일에 흐리게 | |

- 한 날짜에 여러 작품: 포스터를 살짝 겹쳐 최대 2장(PC)·1장(모바일) + `+n`.
- 월 요약: "책 2권 · 영화 3편 · 드라마 1편".
- 연간 보기 [제안] P2: 12개월 격자에 그 달 포스터 썸네일 모음(연말 회고용).

### 3.4 작품 정보 검색 [검증 반영] P1

| 종류 | 1순위 | 2순위 | 비고 |
|---|---|---|---|
| 책 | 카카오(다음) 책 검색 (일 30,000건) | 네이버 책 검색 (검색 API 합산 일 25,000건) | ISBN·표지 제공. 출처 표시 의무 [미확인] → 구현 전 약관 확인 |
| 영화·드라마 | TMDB (`ko-KR`) | 직접 입력 | 비상업 무료. **로고 + "This product uses the TMDB API but is not endorsed or certified by TMDB."** 표시 필수. 6개월 초과 캐싱 금지, 이미지 호스팅 금지 |
| 한국 영화 보강 | KOBIS | | 포스터 제공 [미확인] |

- 검색 요청은 서버를 거친다(API 키 보호, 요청 제한).
- **포스터 저장 정책** [미결정 Q-061]:
  - (a) TMDB 이미지 주소만 저장하고 표시할 때 TMDB 서버에서 불러온다 — 약관에 가장 안전, 외부 의존.
  - (b) 사용자가 "내 기록"으로 저장할 때 이미지를 내 저장소에 복사 — 오프라인·영구 보존에 유리하나 "이미지 호스팅 금지·6개월 캐싱 제한" 조항과 충돌 가능.
  - 추천: **(a) + 사용자가 직접 올린 이미지만 내 저장소에 보관.** 1단계(비상업 개인 사용) 기준. 상업화 시 TMDB 계약 검토.
- 책 표지는 카카오·네이버 약관 확인 후 같은 원칙 적용.

### 3.5 데이터 연결

| 연결 | 규칙 |
|---|---|
| 위시(작품) → 작품 기록 | `읽기 시작`/`보기 시작` 시 제목·이미지·메모 이관, 위시는 "시작함"으로 보존. `다 읽었어요`/`봤어요`/`다 봤어요`는 완료 상태·오늘 날짜로 바로 기록하고 감상 입력으로 이어짐, 위시는 "다 봄"으로 보존 [09 §7] |
| 작품 기록 → 수치 목표 | [05 §3.4](05-goals-and-tracking.md) |
| 작품 기록 → 일정 오버레이 | 선택 표시 |
| 작품 기록 → 일기 날짜별 모음 | "이 날의 다른 기록"에 표시 |
| AI | "올해 읽은 책 몇 권?" "별점 높은 영화 추천해 줘(내 기록 기반)" |

## 4. 예외 상황

| 상황 | 처리 |
|---|---|
| 검색 결과 없음 | `직접 입력하기`로 전환, 입력한 검색어를 제목에 채움 |
| 검색 API 한도 초과·오류 | "지금은 검색할 수 없어요. 직접 입력해 주세요" |
| 외부 포스터 주소가 깨짐 | 기본 표지(종류 아이콘 + 제목)로 대체, 상세에 `포스터 다시 찾기` |
| 종료일이 시작일보다 앞 | 저장 불가, 필드 아래 "끝난 날이 시작한 날보다 빨라요" |
| 읽는 중인 책이 1년 넘음 | 목록에서 "오래 읽는 중" 묶음으로, `중도 포기로 바꾸기` 제안 P2 |

| 기능 | 우선 |
|---|---|
| 일기(여러 주제, 사진, 임시 저장), 일기 목록·날짜별 모음 | P0 |
