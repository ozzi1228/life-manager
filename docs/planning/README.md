# 우나 (oona) 기획 문서

> "우리의 나날들" — 개인용 통합 일상 관리 웹앱(PWA)의 기획 문서 묶음 (프로젝트 폴더 이름: my-life-manager) · 초안 v0.1 · 2026-11-01
> 아직 앱 구현은 시작하지 않았다. 이 폴더는 개발에 바로 쓸 수 있는 명세와, 개발 전에 정해야 할 결정을 담는다.

## 읽는 순서

1. **[00 개요](00-overview.md)** — 무엇을 왜 만드는지, 표식 규칙([확정]·[제안]·[검증 필요]·[미결정])
2. **[18 결정 기록](18-decisions-and-open-questions.md)** — 사용자가 확정한 것, 개발 전 답해야 할 질문
3. **[02 정보 구조](02-information-architecture.md)** → **[03 디자인 시스템](03-design-system.md)** → **[04 화면 명세](04-screen-specifications.md)** — 화면이 어떻게 생기고 움직이는지
4. 영역별 상세(05~12) → 기반(13~16) → **[17 로드맵](17-development-roadmap.md)**

## 문서 간 관계

```
                     00 개요 ──────────────┐
                        │                  │
                     01 요구사항 ◀──────── 18 결정 기록 ◀── 19 연동 조사
                        │                  ▲
          ┌─────────────┼──────────────┐   │
          ▼             ▼              ▼   │
     02 정보 구조 ─▶ 03 디자인 시스템 ─▶ 04 화면 명세
                                       │
     ┌──────┬──────┬──────┬──────┬─────┼──────┬──────┐
     ▼      ▼      ▼      ▼      ▼     ▼      ▼      ▼
    05     06     07     08     09    10     11     12       (영역별 규칙)
   목표    돈    일정   기록   위시   건강    펫     AI
           └──── 20 참은 소비 ────┘  (06 돈 + 09 위시를 잇는 규칙)
     └──────┴──────┴──────┴──────┴─────┴──────┴──────┘
                        │
          ┌─────────────┼──────────────┐
          ▼             ▼              ▼
     13 계정        14 데이터 모델 ─▶ 15 API
                        │
                        ▼
              16 아키텍처·운영 ─▶ 17 로드맵
```

- 화면(04)은 영역 규칙(05~12)을 화면으로 옮긴 것이다. 규칙이 바뀌면 영역 문서를 먼저 고치고 04를 맞춘다.
- 데이터(14)·API(15)는 영역 문서의 필드·규칙을 구현 형태로 옮긴 것이다.
- 외부 서비스 관련 [검증 필요] 판단의 근거는 모두 19에 출처와 함께 있다.

## 표식 규칙 요약

| 표식 | 뜻 |
|---|---|
| [확정] | 사용자가 직접 요청·결정 |
| [제안] | AI 제안, 사용자 승인 전 |
| [검증 필요] | 기술·비용·약관 확인 후 확정 |
| [미결정] | 선택지만 있음, 18번 문서에 질문 번호(Q-xxx) |

화면 문구와 내부 정보 구분: 따옴표 안의 한국어 문구는 화면에 보이는 문구, 영문 필드명·상태 코드·`내부:` 표시는 화면에 노출하지 않는다.
