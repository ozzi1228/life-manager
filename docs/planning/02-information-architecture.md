# 02. 정보 구조 (IA)

> 문서 상태: 초안 v0.1 · 작성일 2026-11-01
> 관련: [03 디자인 시스템](03-design-system.md) · [04 화면 명세](04-screen-specifications.md)

## 1. 설계 원칙

| 원칙 | 내용 | 근거 |
|---|---|---|
| 첫 화면은 요약, 상세는 필요할 때 | 홈은 오늘 할 일과 중요한 변화만. 전체 목록·설정은 각 영역 화면에서. | [확정: 정보 위계] [제안: 구체화] |
| 최상위 메뉴는 5개 | 기능을 메뉴로 늘어놓지 않고 5개 영역으로 묶는다. 모바일 하단 탭 5개와 1:1 대응. | [제안] |
| 자주 하는 행동은 어디서든 한 번에 | 지출 추가·목표 체크·일정 추가·기록 쓰기는 빠른 추가로 어느 화면에서든 진입. | [제안] |
| 설정과 설명 분리 | 설정은 설정 화면·모달, 설명은 i·?·가이드. | [확정] |
| 화면 크기마다 표시 방식이 다르다 | PC는 비교·병렬, 모바일은 오늘·지금 행동 중심. | [확정] |
| 모든 상세 화면은 주소(URL)를 가진다 | 새로고침·뒤로가기·공유(본인 기기 간) 시 같은 화면 복원. 모바일 뒤로가기로 시트가 닫힌다. | [제안] |

## 2. 최상위 메뉴 [제안: 구성] [확정: 자산 라벨 D-046]

| 순서 | 메뉴 라벨 | 아이콘(lucide) | 포함 기능 |
|---|---|---|---|
| 1 | 홈 | `house` | 오늘 요약, 빠른 추가, 위젯 |
| 2 | 일정 | `calendar-days` | 캘린더(월·주·일), 일정, 외부 캘린더, 다른 영역 일정 겹쳐 보기 |
| 3 | 목표 | `target` | 월간 트래커, 전체 목표(단기·중기·장기), 연도별(새해) 목표 |
| 4 | 자산 | `wallet` | 한눈에, 지출(지출 내역·고정 지출), 예산, 카드, 참은 소비, 계좌·투자 |
| 5 | 기록 | `notebook-pen` | 일기, 작품(독서·영화·드라마), 위시, 건강 |

보조 기능(메뉴에 넣지 않음): 검색, 알림, AI 대화(펫), 설정, 펫 관리.

- 위시리스트와 건강은 사용 빈도에 따라 홈 위젯·바로가기로 끌어올릴 수 있지만 최상위 메뉴로 올리지 않는다. [제안]
- 메뉴 라벨 `자산`으로 확정했다(D-046). 검토했던 대안 `돈`, `가계부`는 쓰지 않는다.

## 3. 전체 화면 계층과 주소

`내부:` 주소는 개발용이며 화면에는 노출하지 않는다. 화면 ID는 [04 화면 명세](04-screen-specifications.md)의 절 번호와 맞춘다.

│   ├─ ?event=<id>                  SCR-CAL-02   일정 상세 (PC 오른쪽 패널 / 모바일 Drawer)

│   ├─ /goals/tracker/<yyyy-mm>     SCR-GOAL-02  월간 트래커
│   │   └─ 셀 편집                  SCR-GOAL-03  셀 메모 Popover / Drawer
│   │   └─ 항목 관리                SCR-GOAL-04  트래커 항목 추가·색상 Dialog

전역 오버레이(모든 화면 위에 존재):

| 요소 | ID | 설명 |
|---|---|---|
| 빠른 추가 | SCR-QA | 모바일 `+` 버튼 → 메뉴(Drawer), PC `추가` 버튼(DropdownMenu) + `N` 단축키 |
| 검색·빠른 실행 | SCR-CMD | PC `Ctrl/⌘+K` Command 팔레트, 모바일 상단 검색 아이콘 → 전체 화면 검색 |
| 알림 센터 | SCR-NOTI | PC Popover, 모바일 전체 화면 |
| 펫 | SCR-PET | 최상위 레이아웃에 상주하는 캐릭터 레이어 |
| AI 대화 | SCR-AI | 펫 클릭 → 미니 대화창(PC 플로팅, 모바일 Drawer) → 확장 시 전체 대화 화면 |

## 4. 영역별 기본 화면 결정

각 메뉴를 눌렀을 때 처음 보이는 화면은 "가장 자주 하는 행동"을 기준으로 정한다. [제안]

| 메뉴 | 처음 보이는 화면 | 이유 |
|---|---|---|
| 홈 | 오늘 요약 | 하루 시작·확인 |
| 일정 | 이번 달(PC) / 이번 달 + 오늘 목록(모바일) | 일정은 날짜 맥락이 먼저 |
| 목표 | `월간` 탭의 이번 달 트래커 | 매일 체크하는 행동이 가장 잦다. 장기 목표는 가끔 본다. |
| 자산 | `한눈에` (이번 달 남은 예산 + 결제 예정 + 최근 지출) | 지출 입력은 빠른 추가로 처리되므로, 메뉴 진입 목적은 "얼마 남았나" 확인 |
| 기록 | 마지막으로 연 탭 기억(처음엔 `일기`) | 탭별 용도가 달라 사용자 습관을 따른다 |

## 5. 내비게이션 구조

### 5.1 모바일 (< 768px)

```
┌──────────────────────────┐
│ 상단바: 화면 제목   🔍 🔔 │  ← 홈에서는 날짜 인사말, 오른쪽 검색·알림·프로필
├──────────────────────────┤
│ (영역 내 탭: 가로 스크롤 Tabs) │
│                          │
│        콘텐츠             │
│                          │
│                     (＋) │  ← 빠른 추가 버튼(하단 탭 위 오른쪽)
├──────────────────────────┤
│ 홈  일정  목표  자산  기록 │  ← 하단 탭 5개, 안전 영역 패딩
└──────────────────────────┘
```

- 하단 탭은 아이콘 + 짧은 라벨. 현재 탭은 굵게·기본색. [제안]
- 설정은 상단바 프로필 아이콘 → 메뉴(DropdownMenu)의 `설정`. [제안]
- 상세 보기는 Drawer(하단 시트) 또는 전체 화면 페이지. 입력 필드가 4개를 넘거나 사진·긴 글이 있으면 전체 화면. [제안] → [03 §4](03-design-system.md)
- 키보드가 올라오면 하단 탭과 `+` 버튼은 숨긴다. [제안]
- 펫은 하단 탭 위 가장자리를 주 활동 영역으로 삼는다. `+` 버튼 영역은 피한다. [제안]

### 5.2 태블릿 (768 ~ 1023px)

- 왼쪽 사이드바를 아이콘 모드(접힘)로 표시, 마우스 호버·탭 시 라벨 Tooltip.
- 상세 보기는 오른쪽 Sheet(폭 400px)로 연다.
- 2열 레이아웃까지만 사용.

### 5.3 PC (≥ 1024px)

```
┌────────────┬──────────────────────────────────────────┐
│ 로고        │ 상단바: 브레드크럼        [검색 ⌘K] [+ 추가] 🔔 👤 │
│            ├──────────────────────────────────────────┤
│ 홈          │                                          │
│ 일정        │                                          │
│ 목표   ▾    │         콘텐츠 (2~3열)          │ 상세 패널 │
│  · 월간     │                                │ (선택 시) │
│  · 전체 목표 │                                │          │
│  · 연도별   │                                │          │
│ 자산   ▸    │                                          │
│ 기록   ▸    │                                          │
│            │                                          │
│ ───────── │                                          │
│ 🐾 펫       │                                          │
│ ⚙ 설정     │                                          │
└────────────┴──────────────────────────────────────────┘
```

- 사이드바: shadcn `Sidebar` 컴포넌트, 접기 가능(아이콘 모드), 상태 기억. 하위 메뉴는 현재 영역만 펼침(Collapsible). [제안]
- 상단바: 브레드크럼(현재 위치), 검색 입력 모양 버튼(`⌘K` 표시), `+ 추가`, 알림, 프로필.
- 상세 보기: 목록 화면에서 항목 선택 시 오른쪽 패널(분할 화면)로 열고, 목록은 유지된다. 1440px 미만에서는 Sheet(겹침), 이상에서는 고정 분할(Resizable). [제안]
- 단축키: `N` 빠른 추가, `⌘K` 검색, `G H/C/G/M/R` 영역 이동, `?` 단축키 도움말. [제안]

## 6. 영역 내 탭 구성 [제안]

| 메뉴 | 탭 | 비고 |
|---|---|---|
| 목표 | 월간 · 전체 목표 · 연도별 | 연도별 = 새해 목표 |
| 자산 | 한눈에 · 지출 · 예산 · 카드 · 참은 소비 · 계좌·투자 | 지출 안에 하위 탭 지출 내역 / 고정 지출(D-062). 모바일은 탭이 많아 가로 스크롤. 계좌·투자는 P1 |
| 기록 | 일기 · 작품 · 위시 · 건강 | 건강은 잠금 설정 시 탭 진입에 확인 단계 |
| 일정 | 월 · 주 · 일 (보기 전환, 탭 아님: ToggleGroup) | |

## 7. 화면별 정보 우선순위 요약

각 화면의 자세한 우선순위 표는 [04 화면 명세](04-screen-specifications.md)에 있다. 여기서는 등급 정의와 대표 화면만 정리한다.

| 등급 | 의미 | 표시 방식 |
|---|---|---|
| **A 항상 보임** | 지금 행동을 결정하는 정보 | 기본 화면에 크게 |
| **B 기본 보임** | 맥락 정보 | 기본 화면에 작게(보조 글자색) |
| **C 펼치면 보임** | 부가 정보 | 행 펼침(Collapsible), 상세 패널 |
| **D 요청 시** | 용어 정의·조건·사용법 | i/? Popover, 가이드 |
| **E 숨김** | 내부 정보 | 화면에 노출하지 않음 |

| 화면 | A 항상 보임 | B 기본 보임 | C 펼치면 | D 요청 시 | E 숨김 |
|---|---|---|---|---|---|
| 홈 | 오늘 일정, 오늘 목표 체크, 남은 예산 | 결제 예정, 최근 기록 | 각 위젯 상세 | 위젯 설명 | 위젯 ID |
| 월간 트래커 | 날짜×항목 칸 색, 오늘 열 | 셀 메모(말줄임), 항목별 완료 수 | 메모 전문 | 사용법(?) | 셀 상태 코드 |
| 고정 지출 | 이름, 금액, 다음 결제일, 해지 예정 배지 | 결제수단, 메모 있음 표시 | 메모 전문, 결제 이력 | 주기 계산 규칙 | 계산 내부 값 |
| 카드 | 카드 이름, 이번 달 실적 충족 여부, 남은 할인 한도 | 주요 혜택 2~3개 | 전체 혜택·제외 조건 | 실적·한도 용어 정의 | 규칙 구조 |
| 위시(쇼핑) | 이름, 이미지, 구분(관심/갖고 싶음/필요), 가격, 구매 체크 버튼 | 담은 날 경과, "○월에 참음" | 링크·메모 | 구분 판단 기준 | Like/Want/Need 영문 코드 |
| 참은 소비 | 참아야 할 금액, 참은 금액, 더 참아야 할 금액 | 참은 소비 목록, 이번 달 말 후보 | 금액 내역(사치·분류별 초과·넘어온 금액), 지난 정산 | 계산 방식·자동 포함 조건 | 정산 작업 상태 |

## 8. 영역 간 데이터 연결

```
위시(쇼핑) ──구매함──▶ 지출 ──라벨──▶ 예산 범위
                         │
                         └─결제수단─▶ 카드 ──▶ 실적·한도·혜택 분석 ──▶ AI 카드 추천
지출(사치 분류) + 분류별 예산 초과액 ──▶ 참아야 할 금액 ◀──채움── 참은 소비 목록
                                                        ▲ 직접 기록 / 위시(갖고 싶음·관심, 한 달 내내 안 삼, 월 정산) / 그만둔 위시
위시(작품) ──다 읽었어요·봤어요──▶ 작품 기록(감상)
고정 지출 ──결제일──▶ 일정(겹쳐 보기), 알림, 펫 말풍선
          └─자동 기록(선택)─▶ 지출
위시(작품) ──보기 시작──▶ 작품 기록 ──완독──▶ 목표 진행률(수치형 목표)
작품 기록 ──날짜──▶ 포스터 캘린더, 일정(겹쳐 보기 선택)
트래커 항목 ──연결(선택)──▶ 목표
건강(생리 예정일) ──▶ 일정(겹쳐 보기, 기본 끔)
모든 영역 ──권한 허용 시──▶ AI 비서 조회
```

연결 원칙 [제안]:
- 연결은 **참조**로 만든다. 지출을 지워도 위시는 남고 "연결된 지출이 삭제됐어요"로 표시한다.
- 같은 정보를 두 번 입력하게 하지 않는다. 연결 시 이전 화면 값을 미리 채운다.
- 자동 생성은 항상 되돌릴 수 있어야 한다(토스트 `되돌리기`).

## 9. 빈 상태에서의 탐색 [제안]

처음 가입한 사용자는 모든 화면이 비어 있다. 온보딩에서 묻는 것은 최소화한다.

1. 온보딩 1단계: 이름(표시명) — 건너뛰기 가능
2. 2단계: 관심 영역 선택(목표, 돈, 일정, 기록, 건강) — 선택한 영역의 홈 위젯만 켠다
3. 3단계: 펫 고르기(5종 중 1) — 건너뛰면 펫 없음
4. 이후 각 화면의 빈 상태가 첫 행동을 안내한다(예: 트래커 "첫 항목을 추가해 보세요" + `항목 추가`).
