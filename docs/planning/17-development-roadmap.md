> - 고친 것: PC에서 펫이 전혀 안 움직이던 문제 — Windows "애니메이션 효과"가 꺼져 있으면 브라우저가 움직임 줄이기로 알려 펫이 멈췄음. 기기 설정은 따르지 않고 설정 > 펫 > `움직임`(움직이기 기본·멈추기)으로 고름(D-061)
> - 고친 것: DB 확인 스크립트가 실패해도 통과로 끝나던 문제(`finally`의 `process.exit`가 오류를 삼킴) → 오류를 찍고 실패로 끝남
> - **M-16** 작품(`/records/media`): 책·영화·드라마 직접 입력(제목·저자/감독·표지 사진·상태·기간·별점 0.5 단위·한 줄 평·감상·어디서 칩), 상태는 종류별 이름(읽는 중/완독/중도 포기, 봤어요, 보는 중/다 봄/중도 포기), 끝난 날이 시작한 날보다 빠르면 저장 안 됨. 포스터 캘린더(끝낸 날에 표지, PC 2장·모바일 1장 + `+n`, 드라마 보는 중은 시작일에 흐리게, 읽는 중·보는 중은 상단 칩), 월 요약("책 1권 · 영화 3편"), 종류 필터, 목록 보기(상태 묶음, 중도 포기는 접힘), 상세(감상 없으면 "감상을 남겨 보세요"), 삭제·되돌리기(작품과 기록을 한 묶음으로). 데이터: 작품 1개 + 기록 n개(`media_works`·`media_logs`), 영화는 기록 하나 = 본 날 하나. 확인: `scripts/check-media.mts`. 남은 것: 작품 정보 검색(C-09), 다시 읽기·보기 화면, 목표 연결(C-13), 일정·일기 날짜별 모음 연결, 연간 보기(P2)
> - **M-17** 위시(`/records/wish`): 쇼핑 — 필요·갖고 싶음·관심(i 설명), 가격 필수, 링크 여러 개·사진 10장·어디서 봤는지, 이미지 카드 격자(PC 4열·모바일 2열, 담은 지 며칠째), 정렬 4가지, 모두 사면 합계. **카드의 체크 버튼으로 바로 구매** → 지출 입력이 가격·이름·쇼핑 분류로 채워져 열리고 저장하면 지출 + 구매함이 한 번에(되돌리기 = 지출도 휴지통), "지출 없이 구매함으로". 상세: 사진·링크·날짜, 그만둠(이유 한 줄), 다시 담기, 담아둠으로 되돌리기(연결 지출 남길지 물음), 연결 지출이 지워지면 안내. 작품 — 종류·제목·포스터·메모·링크, 행의 `다 읽었어요`/`봤어요`/`다 봤어요` → 작품 기록 폼이 채워져 열리고 감상 칸에 바로 포커스, 저장하면 위시는 "다 봄"으로. `···`에 읽기 시작·보기 시작(시작함으로). 사진 올리기 칸을 일기·작품·위시가 함께 씀(`src/components/app/photo-picker.tsx`). 확인: `scripts/check-media.mts`. 남은 것: 그만둘 때 참은 소비로 기록·"○월에 참음" 표시(M-22), 링크 미리보기·같은 링크 경고·오래 고민 중 위젯·구분 변경 이력 표시(P1), 공유 메뉴로 담기(P2)
> - **M-22** 참은 소비(`/money/restraint`): 참아야 할 금액 = 사치 분류 지출(환불 차감) + 분류별 예산 초과(사치 분류 제외·예산 없는 분류 0·예정 지출 제외) + 지난달에서 넘어온 금액 + 참았다가 산 물건(`src/lib/restraint.ts`). 진행 카드(참아야 할·참은 금액, 막대, 더 참아야 할 금액·달성, 내역), 직접 기록(위시에서 고르기·이름·금액·날짜·참은 이유), 고치기·삭제·되돌리기, 이번 달 말 후보(1일 전부터 담은 갖고 싶음·관심, "지금 기록"). 월 정산: 화면을 열면 밀린 달부터 따라잡기 — 위시 자동 포함(한 물건은 한 번만, D-039), 부족분 다음 달로(D-040), 지난 달 결과 고정, 정산 뒤 바뀌면 `다시 정산`(뒤 달까지 이어서), 자동 항목 이 달에서 빼기·다시 넣기. 위시: 그만둘 때 "참은 소비로 기록하기"(기본 켬), 카드에 "○월에 참음"·"이번 달에 안 사면 참은 소비로 들어가요", 참은 물건을 사면 산 달 참아야 할 금액에 더하고 구매 화면에 안내, 되돌리면 빠짐(D-041). 지출 토스트에 "참아야 할 금액 +n원"·"그만큼 참아야 할 금액에 더해져요". 확인: `scripts/check-restraint.mts`, `scripts/check-media.mts`. 남은 것: 매달 1일 예약 정산·정산 알림·펫 말풍선(M-21), 부족분 넘기기 끄기 설정, 기록에 이미지·링크, 한눈에 작은 카드·홈 위젯(P1), 분류 설정에서 "참은 소비에 포함" 켜기(분류 관리 화면과 함께)
> - 고친 것(사용자 요청): 트래커 항목 손잡이로 끌어 순서 바꾸기(마우스·터치·키보드 ↑↓, `src/hooks/use-drag-sort.ts`), 항목 수정 창에 "이번 달에서 빼기"와 "삭제" 차이 설명, 고정 지출을 자산 > 지출 탭 안 하위 탭으로(D-062)
